# 股票盯盘工作台（本机运行版）

一个纯前端的 A 股盯盘工作台，数据全部来自**东方财富免费公开接口**，无需账号、无需付费、无需 token。

包含模块：核心指数（实时涨跌幅 + 开/高/低 + 分时线）、自选股（实时行情、分组、成本价浮动盈亏、持仓汇总）、沪深两市预估成交额、涨跌家数 / 涨停跌停家数、盘前分析、每日热点 / 操作 / 复盘等。

**界面已适配手机屏幕**，并可“添加到主屏幕”当作独立 App 使用（PWA：含应用图标、`manifest`、Service Worker 离线外壳）。

---

## 一、准备环境

需要 **Node.js 18 及以上**（用于本地启动一个零依赖的静态 + 代理服务）。

- 下载安装：https://nodejs.org （安装时务必勾选 **Add to PATH**）
- 验证：打开命令行输入 `node -v`，能显示版本号即成功。

> 之所以需要本地服务，而不是双击 HTML 直接打开：东方财富的部分接口（涨跌家数 / 涨停跌停）既不支持浏览器的 JSONP，也不返回 CORS 头，必须由本机服务转发一次。本服务就是干这个的，且**零第三方依赖**，只用 Node 内置模块。

## 二、启动（两种方式任选）

### 方式 A：双击启动（最简单，推荐 Windows 用户）
直接双击本目录下的 **`start.bat`**，它会：
1. 检查 Node 是否安装；
2. 启动服务（后台）；
3. 自动打开浏览器 `http://localhost:3000`。

关闭那个黑窗口**不会**停止服务；要停服务请在任务管理器结束 `node.exe`，或在服务窗口用 `Ctrl+C` 停止。

### 方式 B：命令行启动（跨平台）
在本目录下执行：

```bash
node server.js
```

看到 `✅ 盯盘工作台已启动: http://localhost:3000` 后，浏览器访问 http://localhost:3000 即可。

## 三、使用说明

- **核心指数**：顶部 4 张卡片，显示实时涨跌幅、今开 / 最高 / 最低、底部分时走势。
- **自选股**：点击右上角 **⚙** 打开设置，可增删股票、建分组（持仓 / 观察 / 自定义并配色）；填「成本价 + 持股数」后，自选股上方会出现**持仓汇总条**（实时总浮动盈亏、市值、成本、收益率）。数据存在浏览器 localStorage，不会丢失。
- **涨跌家数 / 涨停跌停**：概览区与「每日热点」处展示，每 15 秒随行情刷新。
- **个股 / 指数详情**：点击任意「核心指数」卡片或「自选股」某一行，弹出详情弹窗——大号实时价 + 涨跌幅、分时走势（默认）与日 K 线（近 120 交易日·前复权·量柱，可切换）、以及今开/最高/最低/昨收/成交额/成交量/换手率/市盈率/总市值/流通市值/振幅/主力净流入等基础数据；弹窗内每 5 秒实时刷新；右下角「🔔 添加预警」可一键为当前标的设预警。
- **价格预警**：点顶栏「🔔 预警」设置（涨跌幅 / 价格 突破或跌破阈值），触发时浏览器顶部横幅 + 提示音 + 系统通知（首次会请求通知权限）；预警弹窗内「触发记录」可查看最近 8 次触发历史。预警在每 5 秒报价时自动检测（仅"穿越"瞬间触发，不会重复打扰）。
- **行情刷新**：报价每 5 秒，分时/指数每 15 秒。

### 自选股 / 分组数据的导入导出
设置弹窗内支持 **导出 JSON**（备份）与 **导入 JSON**（恢复）。JSON 兼容 `group` / `cost` / `qty` 字段。

## 四、常见问题

**Q1：涨跌家数 / 涨停跌停显示 `—`？**
说明 `clist` 接口没取到数。请确认：
- 你是通过 `http://localhost:3000` 访问的（而不是直接双击 HTML 文件打开 `file://`）—— 直接打开文件无法走代理；
- 本机能正常联网访问东方财富。若公司网络对 eastmoney 有限制，可换网络或手机热点。

**Q2：行情报价一直转圈 / 请求失败？**
多为网络或东方财富接口限流，稍等或刷新即可；盘后（非交易时段）部分实时接口返回为空属正常。

**Q3：想部署到服务器 / 云？**
`server.js` 是普通 Node 服务，可放到任意支持 Node 的云主机（如 Render、Railway、自己的 VPS），`PORT` 环境变量可改端口，绑定 `0.0.0.0` 即可公网访问（注意加访问限制）。
已为你部署好一个**带 HTTPS 的云端实例**（可直接在手机上“添加到主屏幕”）：

> 🔗 https://d2d195ba9c794f2ab10b1ce7092ad74d.bj5.agentos-app.net

该云端为静态托管版（界面 / 数据 / PWA 均可用）；若希望「涨跌家数 / 涨停跌停」也最稳（走服务端 `/api/em` 代理而非浏览器 CORS 兜底），把整套文件部署到 Render/VPS 运行 `server.js` 即可，详见 `DEPLOY.md`。

**Q4：同花顺 iFinD？**
本项目默认纯用东方财富免费数据，无需 iFinD。若你有 iFinD 的 `refresh_token`，可在同目录建 `.env` 写入 `IFIND_REFRESH_TOKEN=xxxx`，服务会额外启用 iFinD 真接口（可选，不影响默认功能）。

## 五、手机访问与“添加到主屏幕”

工作台界面已针对手机自动适配：**左侧菜单变为底部标签栏**、卡片单列显示、字号与按钮适配触控；并提供 PWA（应用图标 + `manifest` + Service Worker），可像 App 一样放到手机桌面。

### 1. 让手机连上工作台（手机与电脑同一 WiFi）
1. 电脑上已按上文启动服务（`http://localhost:3000`）。
2. 查电脑局域网 IP：Windows 命令行输入 `ipconfig`，看「无线局域网适配器 WLAN」下的 **IPv4 地址**（如 `192.168.1.20`）。
3. 手机浏览器访问 `http://<电脑IP>:3000`，例如 `http://192.168.1.20:3000`。
   - 若打不开：检查电脑防火墙是否放行 3000 端口入站（可在 Windows  Defender 防火墙放行 `node.exe` 或临时关闭测试）；确保手机与电脑在同一 WiFi。

### 2. 放到手机桌面（添加到主屏幕）
- **iPhone / iPad（Safari，最省事，HTTP 即可）**：点底部「分享」按钮 → 「添加到主屏幕」→ 取名「盯盘」→ 主屏出现图标，点击即以**全屏 App** 打开（无浏览器地址栏）。
- **Android（Chrome）**：**推荐直接用上面 Q3 的 HTTPS 云端链接**打开 → 点右上「⋮」→「安装应用」/「添加到主屏幕」，即可像 App 一样放到桌面（Android 的“可安装”提示要求 HTTPS 安全上下文，局域网 HTTP 不会弹出）。
  - 若坚持用局域网：在电脑本机用 `cloudflared` / `ngrok` 等临时隧道把 `localhost:3000` 暴露成 HTTPS 后再用手机访问。
- 添加后，工作台会以独立图标出现在桌面；Service Worker 已缓存应用外壳，**断网也能秒开首屏**（行情数据仍需联网）。
